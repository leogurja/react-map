---
title: Componente hint
description: Tooltips ao passar o mouse
---

Com hover ativo, o `HintComponent` recebe:

```ts
interface HintProps<T> {
  mouseX: number;
  mouseY: number;
  state: T;
}
```

O hint padrão mostra o nome da região. Passe um componente customizado:

```tsx
<SingleSelectMap map={world} HintComponent={CountryHint} colors={{}} />
```
