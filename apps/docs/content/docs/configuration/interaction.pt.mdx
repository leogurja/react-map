---
title: Interação
description: disableClick e disableHover
---

| Prop           | Padrão  | Efeito                         |
| -------------- | ------- | ------------------------------ |
| `disableClick` | `false` | Desativa clique; cursor padrão |
| `disableHover` | `false` | Desativa hover e hint          |

Use `disableHover` em mapas estáticos. `pathClassName` ainda funciona para hover via CSS.
