---
title: Interaction
description: disableClick and disableHover
---

| Prop           | Default | Effect                                      |
| -------------- | ------- | ------------------------------------------- |
| `disableClick` | `false` | Removes click handler; cursor stays default |
| `disableHover` | `false` | Disables hover tracking and hint            |

Use `disableHover` for static maps or when hints are not needed. `pathClassName` still applies for CSS-only hover if you implement it yourself.
